Arena Map

Physical route abstraction used by the firmware mission counter.

Route model

The AGV starts at BASE, follows the center line, counts blackbox markers, stops at the selected destination, waits for cargo removal, then returns to BASE.

BASEStart and finish node
ALeft return branch
BRight return branch
CFarthest delivery point

Mission checkpoints

Load cell validates cargo, line sensors maintain path tracking, ultrasonic pauses for obstacles, and the dashboard records mission timeline events.
