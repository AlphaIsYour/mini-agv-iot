System Features

Mission Control
Assign destinations (A, B, C) with one click. AGV autonomously navigates, handles intersections, and returns to base.
Real-time Telemetry
Live sensor data streaming: ultrasonic, IR line follower, load cell, motor PWM — all at 2Hz via MQTT.
Analytics Dashboard
Historical event charts, mission success rates, sensor trends, and error tracking — unified dashboard.
RoboEyes Expressions
OLED with animated robot eyes — happy, confused, surprised, angry. AGV shows emotions based on state.
3D Simulation
Interactive 3D arena with Three.js. Visualize AGV movement, tracks, and missions in real-time 3D world.
Obstacle Avoidance
Ultrasonic detects obstacles at 25cm. Servo scans, AGV navigates around and re-finds the line automatically.

Arena Map

Straight-Line Track

The arena features a straight track with 3 delivery destinations and 3 blackbox intersection markers. AGV follows the line from BASE to assigned destination, waits for cargo pickup, then autonomously returns.

Each blackbox marker increments a counter, allowing the AGV to determine when it has reached the correct destination.

BASE — Start
A — Nearest
B — Mid-range
C — Farthest
