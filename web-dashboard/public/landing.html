System Features

Mission Control
Assign destinations (A, B, C) with one click. AGV autonomously navigates line-following path, handles intersections, and returns to base.
Real-time Telemetry
Live sensor data streaming: ultrasonic distance, IR line follower, load cell weight, motor PWM — all updated at 2Hz via MQTT.
Analytics Dashboard
Historical event charts, mission success rates, sensor trend graphs, and error tracking — all in one unified dashboard.
RoboEyes Expressions
OLED display with animated robot eyes — happy, confused, surprised, angry. AGV shows emotions based on mission state.
3D Simulation
Interactive 3D arena built with Three.js. Visualize AGV movement, line tracks, and mission progress in real-time 3D world.
Obstacle Avoidance
Ultrasonic sensor detects obstacles at 25cm. Servo scans left-right, AGV automatically navigates around obstacles and re-finds the line.

Arena Map

Straight-Line Track

The arena features a straight track with 3 delivery destinations (A, B, C) and 3 blackbox intersection markers. AGV follows the line from BASE to assigned destination, waits for cargo pickup, then autonomously returns.

Each blackbox marker increments a counter, allowing the AGV to determine when it has reached the correct destination.

BASE — Start/Return
A — Nearest
B — Mid-range
C — Farthest
